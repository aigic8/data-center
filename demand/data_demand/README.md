# Data Data Center Demand

## Data Sources

There are currently two data sources used in this project:

- [Alibaba Data Source](https://github.com/alibaba/clusterdata)
- [Google Data Source](https://github.com/google/cluster-data)

Alibaba has GPU clusters which is the main idea of this project but there is much less data in Alibaba dataset than in Google's.

Google's has a LOT OF DATA, however there is no data about gpu clusters and usage. There is also power data in Google, which Alibaba's does not have.
