# Energy Systems

## PV System

### Choosing Panels

- The common PV brands for commercial applications are:
  - `SunPower`
  - `LG Solar`
  - `REC Group`
  - `Canadian Solar`
  - `Trina Solar`
  - `Longi Solar`
  - `Jinko Solar`
- Common PV Size for these applications is `450W` panels

### Designing System

- The Max Power of Inverter should match panels
- The Voltage of panels should match the inverter's
